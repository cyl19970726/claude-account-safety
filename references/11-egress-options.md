# 11 出口选型（BYO，不带商家）

本 Skill 不卖、不代购、不保存任何代理/住宅 IP 订阅。这里只给评估维度，具体供应商由你自己选择并在官方渠道购买。

> 如果你实际位于不支持地区，这一节不构成规避授权。先回到 `01-policy-and-boundaries.md` 的地区门禁。

## 三类出口

| 类型 | 优点 | 缺点 | 适合 |
|---|---|---|---|
| 自建 VPS | 可控、可审计、带宽稳定 | IP 多为机房 ASN；需要运维；IP 可能被标记 | 开发/长期在线 |
| 住宅代理 | ASN 更像家庭宽带 | 贵、共享/轮换复杂、日志与合规不透明 | 需要住宅出口且能接受成本 |
| 家庭宽带 | 最自然、稳定 | 不能随身携带；上传/延迟受限 | 固定地点的专用机 |

## 评估维度

问供应商/自己核对这些，不要只看“防封”“纯净”“原生”广告词：

1. **ASN 类型**：住宅、机房、移动、企业。用公开 ASN 查询核对，不信标签。
2. **共享 vs 独享**：多少用户共用同一出口；是否能指定静态 IP。
3. **静态 vs 轮换**：登录/付款期间是否会变；轮换周期是否可控。
4. **IPv4/IPv6**：是否双栈；IPv6 是否会绕过你的规则。
5. **协议**：HTTP(S)/SOCKS5；是否支持 UDP；是否支持链式代理。
6. **地理定位**：IP 注册地、实际出口、时区是否一致；不要只看节点名。
7. **日志与隐私**：是否记录目标域名、时长、流量；保留多久；是否可删除。
8. **KYC/支付**：是否要求身份证明；支付方式是否合规；退款政策。
9. **ToS**：是否允许你的用途；是否允许转售/共享。
10. **稳定性**：晚高峰丢包、长连接断流、DNS 解析位置。

## 采购前的小测试

- 先用最小套餐/试用测试，不要年付。
- 测试 `claude.ai/cdn-cgi/trace` 与 `cloudflare.com/cdn-cgi/trace` 的 `ip`/`loc` 是否一致。
- 测试 DNS 解析器位置。
- 测试 30–120 秒长连接是否断流。
- 测试登录/付款期间出口是否漂移。
- 记录 ASN、地理、时间，不要记录账号凭据。

## 不要把

- 不要把订阅 URL、节点 UUID、密码写进仓库、报告或聊天。
- 不要把“住宅”当成免封证明。
- 不要用公共机场节点登录/付款。
- 不要今天买美国、明天换日本来“测试哪个不封”。
- 不要在账号被限制后换新出口+新号继续。
